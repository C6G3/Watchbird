# Movement-anomaly model benchmark

Generated by `python -m ml.benchmark`. Data: simulated livestock herds (`ml/simulate.py`, the target use case) and 3 real gull tracks (~62k fixes, a hard wide-ranging proxy); first 60% of each track trains, the last 40% is scored after planting anomalies (`ml/inject.py`). Recall counts an anomaly as found if any of its fixes is flagged after the event filter. False/1k = flagged events with no planted anomaly, per 1000 clean fixes (1000 fixes is about 10 days at 15 min).

**Chosen:** `local_outlier_factor {'n_neighbors': 50} q=0.99` (best recall with at most 4 false alarms per 1000 clean fixes on the validation seed). The held-out table shows it trained once for all devices (shared) and once per device.
